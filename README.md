# GreenScape Lawn & Landscape — Portfolio Demo

Responsive fictional landscaping website built as a reusable starter template for small-business freelance projects.

## Customize for a client
1. Replace GreenScape with the client's real business name.
2. Replace fictional phone, email, service area, services, and copy.
3. Replace demo statistics with verified facts, or remove that section.
4. Put client photos in `images/` and replace the graphic project placeholders.
5. Connect the contact form to a production form solution.
6. Update the page title and meta description.
7. Test every link and the mobile layout.
8. Remove demo disclaimers only after all content is real and verified.

## Publish with GitHub Pages
1. Create a public GitHub repository, e.g. `greenscape-demo`.
2. Upload `index.html`, `style.css`, `script.js`, and `images/` to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the Pages address after deployment.
